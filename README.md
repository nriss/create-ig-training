# Training : créer un IG FHIR

Session d'1 heure pour apprendre à créer un guide d'implémentation (IG) FHIR avec quelques artifacts écrits en FSH (profil, extension, jeu de valeurs, exemple). Les exercices se font à partir du template de la branche `ig-template`, que chaque participant fork.

**Prérequis :** un compte GitHub.

Support de la session : <https://nriss.github.io/create-ig-training/>
